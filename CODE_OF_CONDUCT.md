# Code of Conduct

We want this project to be useful to learners and contributors with different backgrounds.

Be respectful, specific, and patient. Critique ideas and implementations rather than people. Do not
harass, threaten, demean, or expose private information. Teaching discussions must not shame a
learner for missing prior knowledge, disability, language, pace, or educational history.

Maintainers may edit or remove abusive, unsafe, off-topic, or privacy-violating contributions and
may restrict participation when necessary. Report conduct concerns privately through the
repository owner's GitHub profile contact route. Reports will be handled as confidentially as
practical, with conflicts of interest avoided where possible.

By participating, you agree to follow these expectations in repository discussions, issues, pull
requests, and project-managed community spaces.
