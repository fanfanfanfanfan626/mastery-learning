# OpenCode adapter

Status: **Planned**.

No OpenCode installer is published in 0.5.0. The project has not yet completed an authoritative
discovery-path review or the required install, trigger, classroom, state, resume, cleanup, and
uninstall tests on OpenCode. Do not copy another host's instructions and label them supported.

Until an adapter and raw test results are added, OpenCode users may inspect the canonical Skills
under `skills/`, but the project makes no installation or behavior claim.
