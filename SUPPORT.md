# Support

Use [GitHub Issues](https://github.com/fanfanfanfanfan626/mastery-tutor/issues) for reproducible
installation, adapter, classroom, state, or documentation problems.

Before opening an issue:

1. read [INSTALL.md](INSTALL.md) and [COMPATIBILITY.md](COMPATIBILITY.md);
2. record the Mastery Tutor version or commit;
3. record the AI host, host version, operating system, and installation method;
4. include the exact failed step and sanitized output;
5. do not upload `.mastery/` learner records unless you have removed personal content.

Use the adapter bug form for host-specific behavior. Feature discussions should describe the
learner problem and a testable outcome, not only a proposed implementation.

Security reports must follow [SECURITY.md](SECURITY.md) and should not be filed publicly.
